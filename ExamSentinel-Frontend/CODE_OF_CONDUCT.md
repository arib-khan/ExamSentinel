# Code of Conduct — ExamSentinel Frontend

## Our Commitment

We are committed to making participation in the **ExamSentinel Frontend** project a respectful, professional, and welcoming experience for everyone.

ExamSentinel is a Final Year Project developed by **Arib Khan** and **Aditya Jaiswal** at **IPS Academy, Indore, Department of Computer Science and Engineering**.

We expect all contributors, maintainers, reviewers, students, educators, and other participants to interact respectfully and constructively.

## Expected Behavior

Participants are expected to:

- Be respectful and professional.
- Communicate clearly and constructively.
- Welcome different perspectives and technical approaches.
- Give and receive constructive feedback professionally.
- Focus criticism on code, ideas, UI decisions, and technical choices rather than individuals.
- Take responsibility for mistakes and work toward resolving them.
- Respect the privacy and confidentiality of others.
- Protect sensitive student, examination, authentication, and system information.
- Follow the project's security practices when handling vulnerabilities or sensitive data.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, intimidation, or personal attacks.
- Threats or deliberately hostile behavior.
- Trolling, insulting, or deliberately disruptive comments.
- Publishing another person's private or sensitive information without permission.
- Sharing passwords, API keys, tokens, database credentials, student information, biometric information, or examination data.
- Deliberately introducing malicious code or security vulnerabilities.
- Intentionally bypassing or weakening authentication, authorization, examination-security, or monitoring controls without an approved reason.
- Sexualized language or unwanted sexual attention.
- Any other conduct that would reasonably make the project environment unsafe or unwelcoming.

## Security and Sensitive Information

ExamSentinel may interact with examination-related and student-related information.

Contributors must never commit or publicly disclose:

- Credentials
- API keys
- Authentication tokens
- Private keys
- `.env` files
- Student personal information
- Biometric information
- Examination records
- Screenshots containing sensitive information
- Production data

Security vulnerabilities should be reported privately according to `SECURITY.md`, not through public GitHub issues.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, code reviews, discussions, documentation, and other project-related spaces.

It also applies when a participant is representing the ExamSentinel project in a public or professional setting.

## Reporting

If you experience or witness unacceptable behavior, report it privately through the project-maintainer contact method configured in `SECURITY.md` or the repository.

Please do not publicly disclose private information or security-sensitive details when making a report.

If a reporting contact has not yet been configured, maintainers should update `SECURITY.md` before making the repository public.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Depending on the circumstances, maintainers may:

1. Ask a participant to stop inappropriate behavior.
2. Remove inappropriate comments, issues, pull requests, or other content.
3. Temporarily restrict participation.
4. Permanently restrict participation for serious or repeated violations.

Actions will be considered based on the nature and severity of the behavior.

## Fair and Respectful Review

Code reviews should focus on improving the project.

Reviewers should:

- Explain technical concerns clearly.
- Suggest practical improvements where possible.
- Avoid personal criticism.
- Consider the contributor's intent.
- Distinguish between required fixes and optional suggestions.

Contributors should respond to review feedback professionally and avoid taking technical disagreement personally.
